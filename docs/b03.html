Say there are 4 stocks, their daily returns are assumed to be normally distributed with means and a covariance matrix. If someone tell us, there was one day the stocks had a portfolio gained such such return. Should we believe it?

Let’s say the portfolio was \((0.20247656, 0.26518714, 0.3566089, 0.17572744)\), and the portfolio return on that day was \(0.01016\). Black-Litterman model says with a known risk free rate and covariance matrix we can compute the stock returns used. We load the data.

Use rJAGS to get posterior distributions of the returns.

Code
set.seed(123)

model_code <- "
model {
  #likelihood
  for (i in 1:N) {
    y[i,] ~ dmnorm(mu, Sigma_Inv)
  }

  # Prior on mean vector
  for(k in 1:K) {
    mu[k]~dnorm(0, 1 /100 ^ 2)
  }

  # Prior on covariance matrix
  Sigma_Inv ~ dwish(I, K+1)
}
"
data_list <- list(
  N = N,
  K=K,
  I = diag(K),
  y=r
)
model <- jags.model(textConnection(model_code), 
                    data=data_list, 
                    n.chains = 5);

Let \(x\) be the portfolio vector, \(r_x\) be portfolio return, \(r_f\) be risk-free-rate, \(S\) be covariance matrix of the stock returns. We have: \[\lambda=\frac{r_x-r_f}{x^TSx}\] Let \(r\) be computed stock returns: \[r=\lambda Sx+r_f\]

Code
#Black-Litterman Model
S=cov(r)
risk.free.rate=.01 #risk free rate
port=c(0.20247656,  0.26518714, 0.3566089,  0.17572744)#envelope portfolio
port.r=0.01016 #portfolio reurn
var_port=port%*%S%*%port
lambda=as.numeric((port.r-risk.free.rate)/var_port)
implied.r=lambda*S%*%port+risk.free.rate

Let $x$ be the portfolio vector, $r_x$ be portfolio return, $r_f$ be risk-free-rate, $S$ be covariance matrix of the stock returns. We have:
$$\lambda=\frac{r_x-r_f}{x^TSx}$$
Let $r$ be computed stock returns:
$$r=\lambda Sx+r_f$$

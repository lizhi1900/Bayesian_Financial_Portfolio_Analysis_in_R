x <-seq(-.2,1.2,length.out=30)
df_obs <- data.frame(x = x, y_obs = y)
n <- length(x)

The \(phi\) matrix does not depend on the data, it needs to be imported into JAG. For model building, the simple formulas are from the link above. I just let JAG outputs some predictions collect them for analysis.

Code
m=20 
L=2

phi=sqrt(1/L)*sin(outer(x+L,pi*1:m,"*")/2/L)

gp_model <- '
model{

  for(i in 1:m){
    S[i]=a^2*sqrt(2*pi)*l^1*exp(-.5*l^2*((i)*pi/2/L)^2)
    beta[i] ~ dnorm(0,1);
  }

  gp <- phi %*% (sqrt(S)*beta );

  for(i in 6:25){
    y[i]~dnorm(gp[i],sigma_y^-2);

  }
  for(i in 1:n){
    y_pred[i]~dnorm(gp[i],sigma_y^-2);
  }
  a ~ dgamma(a1,b1)#amplitude 
  l ~ dgamma(a2,b2)#length_scale
  sigma_y ~  dt(0,10^-2,1)T(0,)#error term 

}'


data_list<-list(y = y, pi = pi, m = m, L=L,
                a1=8, b1=5, a2=1, b2=1,
                phi=phi,n=n)
                  
##parameters to save
jags_pars <- c("y_pred") #
 
model <- jags.model(textConnection(gp_model), data=data_list, n.chains = 5)

As we see Figure 5.1, data points on left-hand-side of blue vertical line are for test back casting, data points on right-hand-side of orange vertical line are for test forecasting. The blue band is 95% confidence interval for prediction. The confidence interval does not cover testing data properly, and the interval is too wide. We may want to use the model to predict stock returns which are more likely to be normally distributed.

Code
out=summary(posterior_sample)
lower=out$quantiles[,1]
